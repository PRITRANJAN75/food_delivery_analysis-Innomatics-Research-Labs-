# 📊 Food Delivery Data Analysis

This project analyzes food delivery platform data by integrating
multiple data sources and performing exploratory data analysis.

## 📁 Datasets Used

- `orders.csv` — Transactional order data
- `users.json` — User master data
- `restaurants.sql` — Restaurant master data

## 🔧 Technologies

- Python
- Pandas
- SQLite
- Matplotlib
- Jupyter Notebook

## 📌 Objectives

- Merge CSV, JSON, and SQL datasets
- Analyze user behavior
- Study revenue trends
- Evaluate membership impact
- Perform city and cuisine-wise analysis
